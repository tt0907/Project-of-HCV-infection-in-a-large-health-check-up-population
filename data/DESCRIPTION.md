# Description of the /data/ directory
To facilitate transparency and re-use, the /data/ directory contains the aggregated datasets required to reproduce the figures presented in the manuscript. 

The data are anonymized and derived from the health check-up database; detailed variable definitions and full names align with the manuscript.

# Description of each file (Main figures)
## Clusterbarplot.csv & Lineplot.csv (-prevalence and -incidence):
   Description: These files contain the aggregated prevalence of anti-HCV and incidence rates of HCV seroconversion.
   
   Used for: Generating Figure 2 (A: Overall/sex-specific prevalence; B: Age-specific prevalence; C: Overall/sex-specific incidence; D: Age-specific incidence).

## Clusterbarplot-vertical1.csv:
   Description: This file contains the aggregated prevalence data across various demographic and clinical subpopulations.
   
   Used for: Generating Figure 3 (Prevalence of anti-HCV in various subpopulations).

## Map.csv (along with chinaprovincecity2.csv, bou and SouthSea geographic data files):
   Description: The Excel file contains the aggregated regional prevalence and incidence data. 
   The bou and SouthSea files are standard shapefiles required as basemaps for rendering the map of China.
   
   Used for: Generating Figure 4 (Geographical disparities in anti-HCV prevalence and HCV seroconversion incidence).

## Forestplot-poisson.csv:
   Description: This file contains the aggregated summary statistics, including incidence rate ratios (IRRs) and 95% confidence intervals, for the potential risk factors associated with HCV seroconversion using Poisson regression for main analysis.
   
   Used for: Generating Figure 5 (Incidence rate of HCV seroconversion and its potential risk factors).

(Note: Figure 1, the study flow diagram, is not generated by code and therefore has no corresponding data file in this directory).

# Description of each file (Supplementary figures)
## Bubbleplot.csv:
   Description: Contains city-level GDP per capita and the corresponding anti-HCV prevalence estimates. 
   
   Used for: Generating Supplementary Figure2 (Relationship between anti-HCV and GDP).

## Forestplot-cox.csv:
   Description: This file contains the aggregated summary statistics, including incidence rate ratios (IRRs) and 95% confidence intervals, for the potential risk factors associated with HCV seroconversion using Cox regression for sensitivity analysis.
   
   Used for: Generating Supplementary Figure 3 (Sensitivity analysis of risk factors).

## risktable.csv:
   Description: These files contain the summary data for the number at risk at each follow-up year.
   
   Used for: Generating Supplementary Figure 4 (Cumulative hazard of HCV seroconversion).

(Note: Supplementary Figure 1, the centers included in the study, is not generated by code and therefore has no corresponding data file in this directory).
