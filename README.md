# HCV infection in a large health check-up population

This repository contains the analysis code and data for the study “Prevalence and incidence of hepatitis C virus infection in a large health check-up population in China: a cross-sectional and longitudinal study of 1.6 million adults” (Sailimai et al, GIGASCIENCE 2026).

The study aimed to estimate the prevalence of anti-HCV and the incidence rate of HCV seroconversion between 2017 and 2023 in a large health check-up population in China, with further analyses across regions and subpopulations.

# Prerequisites

- R (version ≥ 3.6.2). The script will automatically install the required packages if they are not already installed.
- Access to the relevant data files. The data files should be placed in a specified directory. In the current R script, the data path is set to `E:\\HCV_data`. Please modify the path variable in the script to match your local directory.
- After setting the correct data path, the script can be run directly using `Rscript`.

# Input data

The script requires the following files, which should be stored in the `data` folder:

- Data files used for plotting (e.g., Excel files containing aggregated prevalence and incidence estimates).
- Geographic data file (e.g., the `bou` and `SouthSea` files in the `data` folder) for drawing the map of China.

The expected column names and formats follow those used in the manuscript. The data are derived from the health check-up database; detailed variable definitions are provided in the manuscript.

## Running the analysis

1. Open the R script and modify the data directory path (e.g., `"E:/HCV_data"`) to point to the folder containing your data files.
2. Ensure that all required data files are placed in the `data` folder.
3. Run the script using `Rscript analysis.R` or within an R session.

The script will generate the figures presented in the manuscript (Figures 2–5). Figure 1 (study flow diagram) is not generated by the code.

## Output

The main results are provided as data files and are also presented in the accompanying manuscript as figures.

- **Figure 1**: Flowchart of the study participants (not generated by the code).
- **Figure 2**: Prevalence of anti-HCV and incidence rate of HCV seroconversion.
   (generated using `Clusterbarplot.xlsx`, and `Lineplot.xlsx` files in `data` folder)
  - (A) Prevalence of anti-HCV in the total study population, and in male and female participants.
  - (B) Age-specific prevalence of anti-HCV in the total study population, and in male and female participants.
  - (C) Incidence rate of HCV seroconversion in the total study population, and in male and female participants.
  - (D) Age-specific incidence rate of HCV seroconversion in the total study population, and in male and female participants.
- **Figure 3**: Prevalence of anti-HCV in various subpopulations.
  (generated using `Clusterbarplot-vertical1.xlsx` file in `data` folder)
- **Figure 4**: Geographical disparities in the prevalence of anti-HCV and incidence rate of HCV seroconversion.
   (generated using `Map.xlsm`, and `bou` and `SouthSea` files in `data` folder)
- **Figure 5**: Incidence rate of HCV seroconversion and the potential risk factors associated with the incidence of HCV seroconversion.
  (generated using `Forestplot.xlsx` file in `data` folder)
