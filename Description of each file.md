# Description of the /data/ directory
To facilitate transparency and re-use, the /data/ directory contains the aggregated datasets required to reproduce the figures presented in the manuscript. 
The data are anonymized and derived from the health check-up database; detailed variable definitions and full names align with the manuscript.

# Description of each file
## Clusterbarplot.xlsx & Lineplot.xlsx:
   Description: These files contain the aggregated prevalence of anti-HCV and incidence rates of HCV seroconversion.
   Used for: Generating Figure 2 (A: Overall/sex-specific prevalence; B: Age-specific prevalence; C: Overall/sex-specific incidence; D: Age-specific incidence).

## Clusterbarplot-vertical1.xlsx:
   Description: This file contains the aggregated prevalence data across various demographic and clinical subpopulations.
   Used for: Generating Figure 3 (Prevalence of anti-HCV in various subpopulations).

## Map.xlsm (along with bou and SouthSea geographic data files):
   Description: The Excel file contains the aggregated regional prevalence and incidence data. 
   The bou and SouthSea files are standard shapefiles required as basemaps for rendering the map of China.
   Used for: Generating Figure 4 (Geographical disparities in anti-HCV prevalence and HCV seroconversion incidence).

## Forestplot.xlsx:
   Description: This file contains the aggregated summary statistics, including incidence rate ratios (IRRs) and 95% confidence intervals, for the potential risk factors associated with HCV seroconversion.
   Used for: Generating Figure 5 (Incidence rate of HCV seroconversion and its potential risk factors).

(Note: Figure 1, the study flow diagram, is not generated by code and therefore has no corresponding data file in this directory).
